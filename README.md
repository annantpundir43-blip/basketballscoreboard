# 🏀 Basketball Scoreboard

A simple Basketball Scoreboard built using HTML, CSS, and JavaScript.

## Features

* Track scores for Home and Away teams
* Add 1, 2, or 3 points with a single click
* Reset both scores to zero
* Clean and responsive design

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

```text
basketball-scoreboard/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Download or clone the project.
2. Open `index.html` in your web browser.
3. Start keeping score!
